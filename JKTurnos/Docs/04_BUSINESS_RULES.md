# BUSINESS_RULES.md

# Filosofia del Negocio

JKTurnos no vende software.

Vende tranquilidad.

El sistema debe reducir el estres del usuario.

Debe ayudarlo a organizar su trabajo.

No complicarlo.

---

# Principios

El usuario trabaja.

El sistema piensa.

No al reves.

---

# Home

El Home es el centro operativo.

No es un Dashboard tradicional.

Debe responder:

¿Que debo hacer ahora?

---

# Onboarding

Nunca obligar al usuario a configurar todo.

El usuario puede comenzar inmediatamente.

Configurar despues.

---

# Primer uso

Bienvenida.

Nuevo Turno.

Nada mas.

El resto aparece progresivamente.

---

# Recursos

El sistema no administra empleados.

Administra Recursos.

Un recurso puede ser:

Profesional

Empleado

Cancha

Cabina

Consultorio

Vehiculo

Sala

Equipo

Cualquier elemento reservable.

La interfaz debe ayudar al usuario a entender este concepto.

---

# Agenda

La Agenda es el corazon del sistema.

Todo gira alrededor de ella.

No alrededor de formularios.

---

# Clientes

El cliente debe tener historial.

Preferencias.

Notas.

Ultimos turnos.

Proximos turnos.

No solo datos personales.

---

# Servicios

Cada servicio puede crecer.

Color.

Duracion.

Precio.

Categoria.

Configuraciones futuras.

---

# Turnos

Debe ser la accion mas rapida del sistema.

Crear un turno debe tomar pocos segundos.

---

# Configuracion

Siempre progresiva.

Nunca obligatoria.

Nunca interrumpir el trabajo.

---

# UX

El usuario nunca debe sentirse perdido.

Siempre mostrar:

Que hacer.

Que sigue.

Que falta.

---

# Responsive

El sistema debe sentirse nativo.

Desktop.

Tablet.

Mobile.

No simplemente adaptado.

---

# Objetivo final

Convertirse en el centro de gestion diario del negocio.

No solamente en una agenda.
