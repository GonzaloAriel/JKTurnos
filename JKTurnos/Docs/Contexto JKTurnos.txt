IMPORTANTE:

En Edit siempre incluir:

@Html.HiddenFor(x => x.Id)
@Html.HiddenFor(x => x.CreatedAt)
@Html.HiddenFor(x => x.TenantId)
@Html.HiddenFor(x => x.IsActive)

Porque si no EF intenta actualizar CreatedAt con DateTime.MinValue y SQL Server produce:

datetime2 -> datetime out of range

Error ya resuelto.
